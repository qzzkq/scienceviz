# Запрос ресурсов кластера НГУ

Статус: черновик, не отправлен. Адрес получателя уточняется.

**Тема:** Доступ к вычислительному кластеру для проекта CosmicViz

Здравствуйте!

Наша команда разрабатывает CosmicViz — программу моделирования и визуализации
эволюции космологического газа и гравитации. Для распределённой части используем
C++17 и MPI. На первом этапе хотим проверить запуск и обмены на 2–3 узлах,
затем измерить производительность расчёта на трёх узлах.

Подскажите, пожалуйста:

1. Как оформить доступ для команды, какие сведения и согласования нужны?
2. Можно ли выделять 2–3 CPU-узла одновременно, какие CPU, объём RAM и сеть
   доступны между ними? Каковы ограничения времени, памяти и хранения данных?
3. Какие версии MPI, компиляторы C++ и CMake доступны? Какие модули нужно
   загружать для сборки и запуска MPI-программы?
4. Какая используется система очередей и есть ли пример задания на три узла?
5. Доступны ли FFTW и HDF5, в том числе их сборки с поддержкой MPI?
6. Есть ли GPU-узлы: модели GPU, объём видеопамяти, версии CUDA и порядок
   доступа? Это потребуется на последующих этапах проекта.
7. Разрешены ли пользовательские библиотеки, каким способом передавать код
   и результаты, где следует выполнять сборку и короткие проверки?

Будем благодарны за инструкцию для первого запуска и контакт специалиста,
с которым можно согласовать конфигурацию эксперимента.
