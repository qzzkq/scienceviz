# Первый результат распределённой части CosmicViz

18 ноября 2026 года · Богдан Буханов.

## Реализовано

- Разбиение трёхмерной сетки слоями по z с учётом остатка.
- Периодический обмен гало через `MPI_Sendrecv`, включая рёбра и углы.
- Выбор обмениваемых полей и отдельный коммуникатор обмена.
- Общий допустимый шаг через `MPI_Allreduce`.
- Прототип диффузии на существующей `Grid3D`.
- MPI-примеры определения узлов и пинг-понга; инструкция подключения машин,
  таблица оборудования и черновик обращения в кластер.

## Проверка правильности

Окружение: Ubuntu 25.10, Intel Core i5-13420H, 12 логических CPU,
GNU C++ 15.2.0, CMake 3.31.6, MPICH 5.0.2. Все процессы работали на одном ноутбуке.

| Проверка | Результат |
| --- | --- |
| CTest Debug с MPI | 11/11 успешно |
| CTest Release с MPI | 11/11 успешно |
| Исходная сборка без MPI | 2/2 успешно |
| Полные поля от отдельных запусков на 1/2/3 процессах | Побитовое совпадение, максимальная разность 0 |
| Независимый последовательный расчёт | Максимальная разность 0 |
| Затухание мод дискретной схемы | Максимальная ошибка 1.219e-07 |
| Сохранение суммы | Максимальное относительное изменение 5.381e-09 |
| Проверка двух физических узлов на одном ноутбуке | Корректный отказ: unique_hosts=1, требуется 2 |

Сравнены 17×13×19 с гало 1 и 2, а также 8×6×6 с гало 2.
Каждая конфигурация запускалась на 1, 2 и 3 процессах в Debug и Release:
18 расчётов, 12 сравнений с однопроцессным полем.
Отдельные тесты проверяют все текущие поля, повторные обмены, разные порядки
полей, неравномерные и тонкие блоки, общий dt и ошибочные параметры.

## Счёт и обмен

Release, куб 64³, 50 шагов, гало 1. Для каждого числа процессов выполнен прогрев,
затем пять измеряемых повторов. Время в таблице — миллисекунды за весь цикл
из 50 шагов. Представлены медианы максимумов времени фазы по рангам.

| Процессов | Счёт, мс | Обмен, мс | Цикл, мс | Диапазон цикла, мс |
| --- | --- | --- | --- | --- |
| 1 | 301.516 | 1.664 | 303.223 | 301.800–340.349 |
| 2 | 152.199 | 5.345 | 155.504 | 152.973–161.710 |
| 3 | 106.541 | 10.307 | 111.009 | 103.103–114.007 |

Заполнение локального гало x/y включено в обмен, перенос нового поля — в счёт.
Сбор результата, запись файла и последовательная проверка не входят в цикл.
Максимумы разных фаз могут приходиться на разные ранги: складывать их нельзя.
Привязка процессов к ядрам скриптом не задавалась, ноутбук использовался как
обычная рабочая машина. Эти результаты подтверждают работу таймеров и локального
прототипа; выводы о нескольких физических машинах требуют отдельных измерений.

## Как повторить проверку

Из корня репозитория после сборки по [инструкции MPI](../../mpi.md):

```bash
ctest --test-dir build-mpi --output-on-failure
build-mpi-env/bin/mpiexec -n 3 build-mpi/mpi_hello
build-mpi-env/bin/mpiexec -n 3 build-mpi/mpi_diffusion \
  --nx 17 --ny 13 --nz 19 --halo 2 --steps 20
python3 scripts/verify_mpi.py --build build-mpi \
  --mpiexec "$PWD/build-mpi-env/bin/mpiexec"
```
